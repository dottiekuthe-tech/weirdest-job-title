One job title, 37 characters: the weirdest job title, a few words and nothing else.

> Pet Psychic for Goldfish With Anxiety

`main.py` (Python 3.13, standard library only) writes that title, with no
trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
No network, no clock, no randomness: two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
